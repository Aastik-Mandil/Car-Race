

\# Car Race



This project is about the Car Racing Game. It is a 2D game build on the \*\*Pygame\*\* library.

\## Tech Stack



Python, Pygame



\## Run Locally



Clone the project



```bash

&nbsp; https://github.com/Aastik-Mandil/Car-Race.git

```



Go to the project directory



```bash

&nbsp; cd Car-Race

```



Create virtual env



```bash

&nbsp; python -m venv .venv

```



Activate virtual env



```bash

&nbsp; cd .venv/Script

&nbsp; activate.bat

```



Install dependencies



```bash

&nbsp; pip install -r requirement.txt

```



Start the game



```bash

&nbsp; python -m main.py

```



De-activate virtual env



```bash

&nbsp; deactivate

```
