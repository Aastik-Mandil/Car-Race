\# Car Race

This project is about the Car Racing Game. It is a 2D game built on the **Pygame** library.

\## Tech Stack

Python, Pygame


\## Run Locally

Clone the project

```bash
git clone https://github.com/Aastik-Mandil/Car-Race.git
```


Go to the project directory

```bash
cd Car-Race
```


Create virtual env

```bash
python -m venv .venv
```


Activate virtual env

```bash
cd .venv/Script
activate.bat
```


Install dependencies

```bash
pip install -r requirement.txt
```


Start the game

```bash
python -m main.py
```


De-activate virtual env

```bash
deactivate
```
